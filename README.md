My personal site. A static Next.js app with light and dark themes, a command palette (`⌘K`), and a print-ready résumé layout.

## Structure

```
site/          Source: Next.js, React, TypeScript, Tailwind CSS
  src/content/ All site copy, as typed data
index.html     Published site (generated by `npm run publish`)
_next/ …       Published assets
```

GitHub Pages serves the repository root directly. No build runs on GitHub.

## Development

```bash
cd site
npm install
npm run dev        # http://localhost:3000
```

## Publishing

```bash
cd site
npm run publish    # build and copy the static site to the repository root
cd ..
git add -A && git commit -m "Update site" && git push
```
